# Repository Guidelines

Use the repository-level `AGENTS.md` at the project root as the source of truth for coding and workflow conventions.

Path: `./AGENTS.md`

Skills for test work are versioned in `.claude/skills/` (`test-coverage`, `playwright-write-test`, `playwright-debug-test`, `e2e-environment`); the `playwright-test-engineer` subagent in `.claude/agents/` handles delegated E2E tasks.
